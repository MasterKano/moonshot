# Moonshot
Static register of de-risking events, a coming up list, a company screen, and a Norway shelf calendar. Serve this folder and open index.html. The page loads data/events.csv, data/companies.csv, data/smallcaps.json, data/coming_up.json, and the Norway files. After a screen or Norway data update, run python3 scripts/build_coming_up.py to refresh the coming up list and coming_up.ics.
