# Moonshot
Static register of de-risking events, a coming up list, and a company screen. The screen includes the ASX and London list, Nordic small caps, and the Norwegian shelf. Serve this folder and open index.html. The page loads data/events.csv, data/companies.csv, data/smallcaps.json, data/smallcaps_reaction_summary.json, data/coming_up.json, and the Norway files. After a screen or Norway data update, run python3 scripts/build_coming_up.py to refresh the coming up list and coming_up.ics. The Norway calendar file stays at norway_events.ics.
