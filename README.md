# Moonshot
Static register of de-risking events, a coming up list, a company screen, a countries view, and a browser watchlist. The Events tab is one timeline: the pilot register, every screen event, and the Norwegian shelf. The screen includes the ASX and London list, Nordic small caps, one Tel Aviv name, and the Norwegian shelf. Countries covers the Falkland Islands, Namibia, Guyana, South Africa, Gabon, Angola, and Colombia. Pins stay in this browser under moonshot-watch, and a watch= link can move that list. Serve this folder and open index.html. The page loads data/events.csv, data/companies.csv, data/smallcaps.json, data/smallcaps_reaction_summary.json, data/coming_up.json, data/read_across.json, data/slipped.json, the country files, and the Norway files. After a screen, country, or Norway data update, run python3 scripts/build_coming_up.py to refresh the coming up list and coming_up.ics. The Norway calendar file stays at norway_events.ics.
